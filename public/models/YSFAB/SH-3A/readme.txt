「YS FLIGHT SIMULATION SYSTEM 2000」用追加機体
「HSS-2B」海上自衛隊・哨戒ヘリコプター

1.『YS FLIGHT SIMULATION SYSTEM 2000』をインストールしたフォルダー下にある
 "aircraft"　という名のフォルダーに以下のファイルを解凍してください．

        hss2.dat
        hss2.dnm
        hss2coll.srf
        hss2cock.srf
        hss2cors.dnm

2.『YS FLIGHT SIMULATION SYSTEM 2000』をインストールしたフォルダー下にある
 "aircraft"　という名のフォルダーにある "aircraft.lst" ファイルに以下の一文を
追加してください．

aircraft/hss2/hss2.dat aircraft/hss2/hss2.dnm aircraft/hss2/hss2coll.srf aircraft/hss2/hss2cock.srf aircraft/hss2/hss2cors.dnm


補足
当り判定（衝突判定）のために"hss2coll.srf"に「輪」をつけました．
これは『YS FLIGHT SIMULATION SYSTEM 2000』のシステム上 ”プロペラ”を含む衝突
判定ファイルをつくることが困難なためです．しかし「輪」をつけたため場合によっ
て（視点によっては）不自然な影が投影されてしまします．
通常の航空機ではプロペラの接触による墜落は考えにくいのですが、ヘリコプターの場
合はプロペラ（ローター）の接触による墜落が当然発生します．そこでこのような衝突
判定ファイルを作りました．

もし前述の”不自然な影”が不愉快な場合は同梱しました"hss2coll2.srf"を
"hss2coll.srf"にリネームして上記"aircraft"に放り込んでください．（この場合、
ローターによる衝突判定は無効となります）
